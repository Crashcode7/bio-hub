## 🇬🇧 ENGLISH VERSION

Thank you for downloading / purchasing the Bio Hub Template! This is a modern, responsive, and animated bio link website template built with HTML, CSS, and JavaScript.

### 🛠️ How to Customize

You can edit these files using any text editor (such as VS Code, Notepad, or Acode on Mobile):

1. **Change Avatar / Profile Picture (`index.html`):**
   - Option A: Replace the Unsplash URL in `<img src="...">` with your own image link.
   - Option B: Place your photo file (e.g., `avatar.jpg`) inside this project folder and change the code to:
     `<img src="avatar.jpg" alt="Profile Picture" class="avatar-img">`

2. **Change Profile Name & Bio (`index.html`):**
   Locate `<header class="profile">` and edit the text inside `<h1>` and `<p>`.

3. **Update Links (`index.html`):**
   Locate `<main class="links-container">` and replace `href="https://example.com"` with your own URLs.

4. **Update Social Media Links (`index.html`):**
   Locate `<footer class="social-bar">` at the bottom and insert your social media profile URLs.

### 🛠️ Cara Mengubah Isi Web

Kamu bisa mengedit file ini menggunakan aplikasi text editor (seperti VS Code, Notepad, atau Acode di HP):

1. **Ganti Foto Profil (`index.html`):**
   - Opsi A: Ganti URL Unsplash pada `<img src="...">` dengan URL gambarmu sendiri.
   - Opsi B: Masukkan file fotomu (contoh: `avatar.jpg`) ke dalam folder proyek ini, lalu ubah kodenya menjadi:
     `<img src="avatar.jpg" alt="Profile Picture" class="avatar-img">`

2. **Ganti Nama & Bio (`index.html`):**
   Cari bagian `<header class="profile">` lalu ubah teks di dalam `<h1>` dan `<p>`.

3. **Ganti Link Tombol (`index.html`):**
   Cari bagian `<main class="links-container">` lalu ganti `href="https://example.com"` dengan link tujuanmu.

4. **Ganti Sosial Media (`index.html`):**
   Cari bagian `<footer class="social-bar">` di bagian bawah lalu masukkan link akun sosial mediamu.
